โครงสร้างข้อมูลของระบบ

MoveUp ใช้หลักการทางคณิตศาสตร์ดิสกรีต 2 หัวข้อในการจัดการข้อมูลเบื้องหลังหน้านี้ ได้แก่ โครงสร้างต้นไม้ (Tree) สำหรับจัดหมวดหมู่ท่าออกกำลังกาย และ กราฟ (Graph) สำหรับคำนวณเส้นทางการฝึกในสถานีออกกำลังกายแบบวงจร (Circuit Training)

🌳

1) โครงสร้าง Tree — หมวดหมู่ท่าออกกำลังกาย

Root — จุดเริ่มต้นของต้นไม้ทั้งหมด Parent — โหนดหมวดหมู่ Leaf — ท่าออกกำลังกายจริง (ไม่มีลูก)
🕸️

2) โครงสร้าง Graph — เส้นทางสถานีออกกำลังกาย (Circuit)

Vertex — สถานีออกกำลังกาย Edge — เส้นเชื่อม (น้ำหนัก = วินาทีที่ใช้เคลื่อนที่) Path — เส้นทางที่คำนวณได้
→
ประโยชน์ของ Graph และ Tree ในระบบ

🌳 Tree ช่วยจัดโครงสร้างข้อมูล

การจัดหมวดหมู่ท่าออกกำลังกายแบบ Tree ทำให้ค้นหาและกรองข้อมูลได้เร็วขึ้น เพราะไม่ต้องไล่ดูทุกท่า เพียงไล่จาก Root ลงไปตามหมวดที่ต้องการ (O(สาขาที่เกี่ยวข้อง) แทนที่จะเป็น O(ทุกท่า)) และยังขยายเพิ่มหมวดหมู่ย่อยหรือท่าใหม่ได้ง่าย โดยไม่กระทบโครงสร้างเดิม

🕸️ Graph ช่วยแก้ปัญหาเส้นทาง

การมองสถานีออกกำลังกายเป็น Graph ทำให้ระบบคำนวณ "เส้นทางที่ดีที่สุด" ได้ตามเงื่อนไขต่างกัน เช่น จำนวนสถานีน้อยสุด (BFS) หรือเวลารวมน้อยสุด (Weighted/Dijkstra) และยังใช้ DFS เพื่อออกแบบวงจรการฝึกที่ครอบคลุมทุกสถานีโดยไม่ต้องกำหนดลำดับตายตัวล่วงหน้า
